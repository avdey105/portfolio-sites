Каждый ZIP содержит файлы одной автономной статической демонстрации. Можно распаковать архив и открыть `index.html` через локальный HTTP-сервер. Формы, корзина и бриф работают в браузере. Для заказов, оплаты и отправки заявок эти версии не используются.
