Мобильное приложение · MVP

AlterEgo

За советом к своему второму «я».

Заказчику нужна была рабочая версия приложения для встречи с инвестором. Я сделал её с нуля. Пользователь проходит короткую анкету, обсуждает с нейросетью желаемые качества персонажа и добавляет фотографию. В результате он получает образ своей улучшенной версии — альтер эго, похожего на него. Затем можно спросить, как эта личность поступила бы в конкретной ситуации. Нейросеть отвечает с учётом характера персонажа и ранее предоставленных пользователем данных.

Для встречи с инвестором разработал MVP с нуля. В анкете человек выбирает качества персонажа. По ответам и фото нейросеть создаёт второе «я». В чате можно спросить, как оно поступило бы на вашем месте.

Дагдел

Одна корзина для четырёх разделов.
